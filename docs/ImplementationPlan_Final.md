# PROJECT IMPLEMENTATION
# Eras Tu | Private Boat Tours in Kekova

---

# 1. PROJECT OVERVIEW

## Objective

Develop a premium, SEO-focused, bilingual (Turkish & English) website for Eras Tu, a private family boat operating in the Kekova / Üçağız region.

The website's primary goal is NOT to look flashy.

The primary goal is:

- Generate reservations.
- Rank on Google for local searches.
- Increase trust.
- Convert visitors into WhatsApp conversations.

Every design and technical decision should support these goals.

# 27. AI IMPLEMENTATION RULES

Whenever implementing a feature:

1. Explain the architecture first.

2. Explain why it is implemented that way.

3. Write production-quality code.

4. Keep components reusable.

5. Follow Next.js best practices.

6. Maintain high SEO standards.

7. Prioritize mobile responsiveness.

8. Keep performance above 90 Lighthouse.

9. Never generate unnecessary code.

10. Wait for approval before moving to the next major implementation step.

The goal is not simply to build a website.

The goal is to build the strongest digital presence for a private boat tour business in the Kekova region.
